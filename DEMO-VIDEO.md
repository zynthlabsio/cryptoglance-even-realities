# Demo video — `demo.mp4` (2:28, 1920×1080, H.264 + AAC narration, 4.5 MB)

Follows DEMO-SCRIPT.md end to end: the app's in-browser 576×288 preview (identical screens to the glasses) was driven headlessly with Chromium/CDP through the real flow — watchlist → scroll → BTC detail → paper buy $10 via the confirm screen → "Paper buy done" → paper portfolio (cash $990, BTC position, PnL) → set alert at +5% → "Alert set" → alerts list → end card — captured frame-by-frame (`scripts/capture-demo.mjs`), captioned on every segment, narrated with synthesized speech (Google Translate TTS via `requests`), and assembled with PIL + ffmpeg.
